Opening QRZero on a Mac the first time

The Mac version is not signed with an Apple Developer account, so macOS warns about it on first launch. The file is fine.

Drag QRZero into Applications, then do one of these:

  1. Control-click (right-click) QRZero, choose Open, and click Open in the warning.
  2. Or try to open it once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. Or run this in Terminal:
xattr -dr com.apple.quarantine /Applications/QRZero.app

If macOS says QRZero is damaged and can't be opened, use the Terminal command. It only needs to be done once per downloaded version.

Where your log lives

Windows%APPDATA%\QRZero\qrzero.db
macOS~/Library/Application Support/QRZero/qrzero.db
Linux~/.local/share/QRZero/qrzero.db

QRZero checks GitHub once a day for a newer release and shows a link in the top bar. It never downloads or installs anything for you, and the check can be turned off in Settings → General.

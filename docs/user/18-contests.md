# Contests

The Contests pane lists the contests that are on the air now and the ones coming up in the next two months. Open it from **Layout**, **Contests**. It sits next to the DXpeditions pane to start with; drag the tab anywhere you like, or pop it out to its own window.

It is a calendar only. QRZero doesn't log contests; use your contest logger for that (QRZero can take the QSOs from N1MM, see the UDP page).

## Where the list comes from

QRZero reads the [WA7BNM Contest Calendar](https://www.contestcalendar.com/) feed when it starts and every few hours after that. The last copy is kept in your log database, so the list is still there offline and after a restart. Press **Refresh** to read it now (it ignores a second press within a minute). If the feed can't be read, a message says so and the last list stays on screen.

Contests that have finished are dropped.

## What the list says

| Column | Meaning |
| --- | --- |
| **Contest** | The contest's name as the calendar gives it. |
| **When (UTC)** | Start and end. A contest with several parts (some VHF and sprint contests) shows from the first start to the last end; the calendar's page has the details. |
| (next column) | **ends in** for a contest on the air now, **in** for one still to come. |
| **Mode** | CW, Phone and/or Digital when the contest's name says so (for example "CW", "SSB", "RTTY"). **Any** when it doesn't, as in a mixed-mode contest. |
| **Rules** | Opens the contest's page on the calendar, which links to the sponsor's rules. |

**On now** comes first, then **Upcoming**, each in date order.

## Mode filter

The box at the top picks All modes, CW, Phone or Digital. A contest whose mode isn't named stays in the list whichever you pick. The choice is remembered on this computer.

## Dates and times

All times are UTC. The calendar is a volunteer's page and the sponsors change dates now and then, so check the rules before you plan around a contest.
